# Sicherheitsmeldungen

Bitte mögliche Schwachstellen vertraulich per E-Mail an **c@root-shell.de** melden, Betreff „FileTandem security“.

Hilfreich sind die betroffene Version, Umgebung, Beschreibung der Auswirkungen und eine möglichst kleine Reproduktion mit Beispieldaten. Bitte keine produktiven Passwörter, privaten Schlüssel oder unbereinigten Transferjournale senden. Eine feste Reaktionszeit wird nicht zugesagt.

Fehler ohne Sicherheitsbezug und Verbesserungsvorschläge können über [GitHub Issues](https://github.com/DrWhiteLetter/FileTandem/issues) gemeldet werden.

Vor produktiven Transfers zunächst mit Testdaten prüfen. Automatische Ordnerspiegelung kann entfernte Einträge entfernen. Die Modi zur Transferprüfung, Sicherungen und Grenzen sind in der README dokumentiert.
