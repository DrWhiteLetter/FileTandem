# FileTandem-Logo

Erstellt am 08.10.2026 mit dem integrierten Imagegen-Tool. Transparenter PNG-Hintergrund, Original in `media/filetandem-logo.png`, auf 64 × 64 Pixel skalierte Button-Version in `media/filetandem-button.png`. Der Button ist in der Titelzeile der Verbindungen-Ansicht eingebunden und ruft `filetandem.openManager` auf.

## Generierungsprompt

```text
Use case: logo-brand
Asset type: FileTandem software logo used on a small VS Code launch button and extension listing.
Primary request: Create one polished distinctive compact symbol representing two side-by-side file manager folders linked by bidirectional file transfer arrows, expressing tandem cooperation.
Style: modern minimal flat vector-like logo, bold clean silhouette, carefully balanced geometry, restrained rounded corners, professional developer tool. Use the familiar cool blue/teal visual language of file transfer tools, with enough contrast on light and dark UI.
Composition: one centered square symbol, occupies most of canvas with modest clear margin; exactly two folder/window forms and a clear exchange connection, few large shapes readable when reduced to 24 pixels.
Backdrop: genuinely transparent alpha background.
Constraints: symbol only, no text, no lettering, no mockup, no border around canvas, no shadows, no fine details, no gradients or 3D, no watermark.
```
