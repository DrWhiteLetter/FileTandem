# M2-05 – SFTP-Browser

RemoteFileService bietet stat/readdir/readlink und explizite SFTP-Fähigkeiten, ohne Shell oder exec. POSIX-Pfade werden getrennt von lokalen Pfaden behandelt. Generationen im DirectoryBrowser verhindern veraltete Antworten und Fehler nach Ordnerwechsel/Trennung. Kanal-/Transportende und Zeitlimits lehnen ausstehende Aufrufe ab. Quality und echter Integrationstest auf der SFTP-only-Fixture bestanden. Zusätzlich echte Passwort-/verschlüsselte-Key-Anmeldung über den neuen Credential-/SessionManager, sicherer Speicher und Wiederverbinden bestanden. SCP-Dateiverwaltung ist ausdrücklich erst M4; kein stiller Protokollwechsel.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
