# M0-09 – Technische Entscheidungen und M0-Abschluss

Datum: 7. Oktober 2026. Zugehöriger Commit: `docs(M0-09): finalize technical decisions and close milestone M0`.

**Ergebnis: M0-09 und M0 abgeschlossen. Alle neun M0-Items sind abgenommen; M1 kann mit M1-01 beginnen.** Die Abschlussentscheidung betrifft die technische Entwicklungsgrundlage, keine Produkt-/Plattformfreigabe für Version 1.0.

## Ergebnis und Recherche

[Entscheidungen](../entscheidungen.md) enthalten zehn verbindliche Festlegungen mit Alternativen, Vor-/Nachteilen und Konsequenzen. Recherche ausschließlich anhand der Primärdokumentation von VS Code, ssh2 1.17.0, ssh2-sftp-client, OpenSSH, React und der MIT-Lizenzbedingungen. Quellen stehen jeweils direkt bei der Entscheidung. Versionswahl/Performancebewertung beruhen auf eigenen M0-Nachweisen; „neueste Version“ wird nicht mit „geprüfte Version“ gleichgesetzt.

Gewählt: lokaler Desktop-UI-Host, JavaScript/React/esbuild, ssh2 direkt, verpflichtender eigener Host-Key-Trust, SFTP-Standard, eigener echter SCP-Adapter für das Linux/POSIX/GNU-Profil, begrenzter geschützter SFTP-Editor, lokale SCP-Bearbeitung mit explizitem Rück-Upload und eine universelle private VSIX ohne native Pflichtmodule. Vollständige Profile/SecretStorage bleiben M2-Aufgaben. MIT ist die gewählte Lizenzrichtung für die spätere Auslieferung; Datei und Produktmetadaten sind M6-08, kein öffentlicher Publish in M0.

[Kompatibilität](../kompatibilitaet.md) protokolliert exakte Versionen, geprüfte Desktop-/Fenster-/Auth-/Serverkombinationen, Prototype-Limits und eine Risiko-/Ersatzmatrix mit zuständigen späteren Items. Für das Datei-Ziel gibt es keine VS-Code-Server-/glibc-Pflicht. Diese Anforderungen betreffen ausschließlich ein separat genutztes Remote-SSH-Arbeitsfenster.

Manifest, Lockfile, normaler Teststarter, Editor-Teststarter und Test-Harness-Manifeste wurden auf **VS Code 1.140.0** abgestimmt. `^1.140.0` ist die installierbare Untergrenze; Defaulttests laden genau 1.140.0. Die bisherige 1.139.0-Angabe war nicht vollständig abgenommen. Abhängigkeiten bleiben unverändert fixiert; keine ungeprüften Updates.

Plan, README und Meilensteinübersicht sind aktualisiert. M3/M4/M5/M6 erhalten angepasste Aufwände, M4 explizit die kontrollierte Anhebung des SCP-Größenlimits für den >4-GiB-Test, M5 den entschiedenen SCP-Kopierworkflow und Sitzungs-URIs. Restaufwand M1–M6: **31–46 Personenarbeitstage**, mit 20 % Reserve aufgerundet **38–56**. SFTP-Alpha ab jetzt: 14–21 ohne Reserve, 17–26 mit Reserve. Keine gemessene M0-Ist-Zeit wird erfunden.

## Abschlussprüfung

- `npm run check`: JavaScript-Syntax einschließlich angepasster Starter bestanden.
- `npm test` mit tatsächlichem VS Code 1.140.0: 18 Unit-Tests, Build und echter Extension-Host-Smoke (Aktivierung, lokaler Marker-SHA-256, URI-Abgrenzung, Webview-Start) bestanden.
- `npm run test:packaging` mit tatsächlichem VS Code 1.140.0 und ausschließlich eigenen Fixtures: private VSIX erzeugt, Inhalt geprüft, sauber installiert/aktiviert; gebündelte SSH-Authentifizierungen und Editor-API-/Command-Registrierung bestanden. Keine Geheimnisse, nativen Module, Testmaterial oder Entwicklungsabhängigkeiten im Paket. Die neue Manifest-Untergrenze wurde in der tatsächlichen VSIX geprüft.
- `npm audit --json` sowie `npm audit --omit=dev --json`: jeweils **0 gemeldete Schwachstellen**. Momentaufnahme am 7. Oktober 2026, kein allgemeiner Sicherheitsbeweis.
- 85 lokale Markdown-Ziele/Fragmente, Manifest-/Lockfile-Konsistenz, gepinnte Testbaseline und 9/9 M0-Checkboxen geprüft; `git diff --check` bestanden.

Keine Transport-/Editorimplementierung geändert. Ihre echten Protokoll-, Auto-Save- und Remote-SSH-Abnahmen stammen aus M0-04 bis M0-08; für den Abschluss wird die neu eingeschränkte Baseline mit realem Host und realer installierter VSIX geprüft. Historische Nachweise bleiben unverändert nachvollziehbar. Eigene Testcontainer/Netzwerk werden entfernt, das Colima-Profil gestoppt; normale Profile, persönliche Agenten und externe Server bleiben unberührt.
