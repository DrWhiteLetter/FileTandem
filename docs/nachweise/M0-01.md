# M0-01 – Entwicklungsgrundlage starten

Datum: 7. Oktober 2026. Zugehöriger Commit: `feat(M0-01): initialize extension development foundation` (dieser Nachweis gehört zum Implementierungscommit).

## Umgebung und Umsetzung

macOS 26.6.2 / Darwin 25.6.0, Apple Silicon arm64; Node.js 22.13.1, npm 10.9.2; installierter VS Code Desktop 1.139.1. esbuild 0.28.2, React/React DOM 19.3.0, @vscode/test-electron 3.1.0, @types/vscode 1.138.0; Versionen im npm-Lockfile fixiert. Für 1.139.0 ist kein Typenpaket veröffentlicht; die verwendeten stabilen APIs sind in 1.138.0 enthalten. Manifest-Untergrenze vorläufig 1.139.0; endgültige Versionsentscheidung in M0-09.

JavaScript-ES-Module, JSDoc, jsconfig, getrennte Node-/Browser-Bundles, minimales React-Webview mit Theme-CSS und CSP. Startbefehl `xscp.openManager`, `npm start`, F5-Konfiguration mit vorgeschaltetem Build und Source Maps. Keine SSH-Funktionalität in diesem Item.

## Prüfung

- Saubere Quellkopie ohne node_modules und dist unter kurzem `/tmp/xscp-*`-Pfad: `npm ci`, `npm run check`, `npm test` mit installierter VS-Code-Programmdatei über `VSCODE_TEST_EXECUTABLE`.
- Installation aus Lockfile erfolgreich; npm meldet keine bekannten Schwachstellen.
- Syntaxprüfung und beide esbuild-Bundles einschließlich CSS und Source Maps erfolgreich.
- Echter Extension-Host-Smoke-Test: Extension gefunden und aktiviert, Startbefehl registriert, Befehl ausgeführt und xScp-Webview-Tab sichtbar; Exitcode 0.
- `npm start` im Arbeitsverzeichnis erfolgreich: separates Development-Host-Profil und Prozess mit `--extensionDevelopmentPath` gestartet, CLI-Exitcode 0.
- `git diff --check` erfolgreich.

## Grenzen

Die sichtbare React-Ausgabe und F5-Bedienung sind zusätzlich manuell prüfbar gemäß README; der automatisierte Host-Test prüft den Webview-Tab, nicht dessen DOM. Windows/Linux und Remote-SSH sind nicht geprüft. Lokaler Ausführungsort folgt in M0-02.

Beim ersten sauberen Testlauf war der macOS-Temporärpfad zu lang für den Unix-Socket des VS-Code-Testprofils. Derselbe Test besteht unter kurzem Checkout-Pfad. Ein geerbtes `ELECTRON_RUN_AS_NODE` wird im Teststarter entfernt, damit VS Code als GUI startet.
