# M3-08 – Journal und Unterbrechungszustände

Transfermetadaten werden ohne Zugangsdaten serialisiert, über eine exklusive temporäre Datei synchronisiert und atomar veröffentlicht. Beschädigte Dateien werden separat aufbewahrt, ungültige Einträge verworfen und gemeldet. Offene Aufträge erscheinen nach Neustart als unterbrochen; kein automatischer Schreibvorgang und kein ungeprüftes Resume. Unit-Tests prüfen Korruption und expliziten Retry. Zwei reguläre isolierte Starts der frisch installierten VSIX bestehen: Upload nach Tab-Schließen, binärer Ordner-Rundlauf, erhaltene Erfolge und ausschließlich ausdrücklich gestarteter Retry nach Neustart. Qualitätssuite bestanden. Journalgrenze: 10.000 Aufträge / 32 MiB, Überschreitung wird gemeldet.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
