# M3-01 – Aufträge und Scheduler

Einzelaufträge mit Batch-Zuordnung, explizitem Zustandsautomaten, Zielpfadsperren einschließlich überlappender Unterpfade und maximal zwei aktiven Transfers pro Server. Queue-/Batch-Snapshots enthalten nur Metadaten. Quality und Scheduler-Test bestanden: Parallelitätsgrenze, gleiches Ziel, unzulässige Übergänge und Teilfehler ohne Batch-Gesamterfolg.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
