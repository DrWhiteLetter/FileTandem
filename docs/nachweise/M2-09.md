# M2-09 – Profile und Verbindungsansichten

TreeView zeigt persistente Profile, Favoriten und Sitzungszustände; native Kontextaktionen bearbeiten, verbinden, trennen und verbinden erneut. Schnellverbindungen sind nicht persistent und speichern keine Geheimnisse. Commander kann ein ausgewähltes Profil anbinden, ohne den lokalen Ordner zu wechseln. Gespeicherte UI-Zustände restaurieren Pfade/Sortierung und Profilzuordnung ohne automatische SSH-Verbindung. Profiländerung/-löschung trennt vorher die alte Sitzung. Quality, echte SFTP-Dateiverwaltung und eine installierte VSIX in zwei normalen isolierten VS-Code-Starts bestanden: Profil/Favorit/Host-Key-Vertrauen bleiben erhalten; lokaler und SFTP-only-Browser starten ohne Projekt; Trennen/Wiederverbinden, lokaler Rename-Konflikt und echter OS-Papierkorb funktionieren. Der spezielle Restart-Test verwendet bewusst keine extensionTestsPath-Option, weil VS Code in diesem Modus globalState nur im Speicher hält. Native visuelle Bedienmatrix sowie Windows/Linux bleiben getrennte M6-Abnahmen.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
