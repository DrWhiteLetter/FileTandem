# M3-02 – Streaming-Pipeline

Eigener SFTP-Kanal je Transfer auf verifiziertem Backend-Transport, unabhängig vom Browser-Kanal. Node-Pipeline mit Backpressure und 64-KiB-Puffern, Byte-/SHA-256-Metadaten und Cancellation. Quelle wird auf reguläre Datei und unveränderte Größe/mtime geprüft; Dateibytes verlassen den Backend-Prozess nicht. Quality und realer bidirektionaler 16-MiB-SFTP-only-Test bestanden; Hashes stimmen, Navigation läuft während Upload und nach Abbruch weiter.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
