# M4-01 – SCP-Parser härten

Der Parser begrenzt Header und Pakete, verarbeitet fragmentierte/zusammengefasste Pakete ohne Ganzdateipuffer und verlangt vollständigen Inhalt vor Abschlussbestätigung. Größen bis Number.MAX_SAFE_INTEGER werden exakt behandelt; Header über 4 GiB bestehen. Ungültige Größen, Traversal, unerwartete Namen, UTF-8, ACKs, vorzeitiges EOF und zusätzliche Daten werden abgewiesen. Unit-Suite und Lint bestanden. Ein tatsächlicher Über-4-GiB-Lasttest bleibt M6-04.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
