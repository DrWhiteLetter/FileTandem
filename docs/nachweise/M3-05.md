# M3-05 – Rekursive Transfers

Schrittweise No-Follow-Entdeckung mit Verzeichnis- vor Kindaufträgen und Abhängigkeiten. Leere/verschachtelte Ordner werden angelegt; vorhandene Ordner werden zusammengeführt, Datei-Konflikte bleiben explizit. Symlinks/Spezialdateien werden sichtbar übersprungen. Dateien behalten Bytes, sichere 0777-Modusbits und mtime; keine setuid/setgid-, UID-/GID-Übernahme. Neue Ordner verwenden sichere Standardrechte. Bäume sind auf 10.000 Einträge/Tiefe 100 begrenzt; Entdeckungsfehler erzeugen einen fehlgeschlagenen Batch-Auftrag. Quality und realer rekursiver Upload-/Download-Test mit leerem Ordner, binären CR/LF/NUL-Daten und Symlink bestanden.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
