# M6-03 – Fehler- und Datenintegritätsprüfung

Stand: 08.10.2026, private FileTandem-Version 0.0.8, macOS Apple M1/arm64. Erneuter Testlauf nach M6-05/M6-06 gegen ausschließlich eigene lokale SSH-Fixtures.

## Prüfumfang

| Fall | Beleg |
| --- | --- |
| Netzunterbrechung während Upload | Echter TCP-Abbruch für SFTP/SCP; Queue meldet Fehler; SHA-256 des bisherigen Ziels und einer fremden Partial bleiben erhalten; Bereinigung entfernt nur die eigene Partial. |
| Remote-Datenträger voll | 2-MiB-Upload auf 1-MiB-tmpfs; keine Veröffentlichung; altes Ziel unverändert. |
| Lokaler Datenträger voll | 32-MiB-Download auf isoliertem 16-MiB-HFS+-Volume; tatsächliches ENOSPC; bestehendes Ziel bleibt erhalten. Volume anschließend ausgehängt und entfernt. |
| Abbruch beim Finalisieren | Abbruch nach Metadatenvorbereitung vor Veröffentlichung; bisheriges Ziel bleibt erhalten. |
| Kurz unterbrochener Transport | 500-ms-TCP-Pause; abschließender Hash korrekt. Dies ist kein Systemruhezustandstest. |
| Symlinks und sichere Fortsetzung | Reale Protokoll-/Baumtests: keine Linkverfolgung bei rekursiven Transfers; sichere Löschplanung; falsche Präfixe/geänderte Quellen/Profilidentitäten blockieren Fortsetzung. |
| Neustart und Reload | Installierte VSIX in eigenen Profilen; unterbrochene Aufträge starten nicht automatisch; expliziter Retry mit korrektem Hash. |
| Zwei gleichzeitige Fenster | Für SFTP/SCP konkurrieren zwei Quellen um ein neues Ziel: genau ein vollständiger Gewinner, sichtbarer Konflikt im anderen Fenster; keine vermischten Daten. Kein globaler Lock/CAS für vorhandene Ziele behauptet. |

Restart/Reload/Zwei-Fenster-Prüfungen werden auf VS Code 1.140.0 und 1.141.0 ausgeführt. Rohdaten und Logs: `out/m6/faults/`. Der neue gezielte Runner `npm run test:faults` umfasst auf macOS neun Schritte und verwendet ausschließlich isolierte Profile. Der erste erneute Lauf enthält zusätzlich die vorhandenen Installations-/Editor-/Restricted-/Webview-Prüfungen; diese Zusatzprüfungen verändern den gezielten künftigen Prüfumfang nicht.

**Ergebnis des erneuten Laufs:** alle 19 Schritte erfolgreich, darunter 31/31 reale Protokolltests, 6/6 Integritätsfälle und lokale ENOSPC-Prüfungen für beide Protokolle. Alle sechs M6-03-Fensterprüfungen (Restart/Reload/zwei Fenster je Version) bestanden. [Verdichtete Ergebnisse](M6-03-Ergebnisse.json).

## Offener Restpunkt

Der Benutzer hat ausdrücklich **„Jetzt keinen Systemruhezustand auslösen“** gewählt. Deshalb wurde der Mac nicht schlafen gelegt. Echter System-Suspend/Resume bleibt offen; weder TCP-Pause noch Reload werden als Ersatz abgehakt. **M6-03 bleibt als Gesamtitem offen**, bis dieser letzte Fall mit Nachweis geprüft ist. Bereits durchgeführte Teilprüfungen brauchen deshalb nicht als ungeprüft behandelt zu werden.

Weitere Release-Gates bleiben im [M6-Backlog](../meilensteine/M6.md) dokumentiert. Zugehöriger Commit: M6-03-Prüfungen mit diesem Nachweis.
