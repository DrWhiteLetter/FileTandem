# M1-02 – Manifest und Aktivierung

7. Oktober 2026. Commit: `feat(M1-02): add connection view and enforce desktop trust policy`.

Activity-Bar-Container mit eigenem SVG, native Verbindungs-TreeView und Aktualisierungsaktion. Der einzige Eintrag öffnet ausdrücklich eine Demo, keinen Server. Anwendungseinstellungen für versteckte Dateien und Demo-Darstellungszustände; keine Credentials in Settings. Commands/Views aktivieren lazy über stabile Manifestbeiträge; nur Webview-Wiederherstellung hat ein explizites Activation-Event. Kein `*`, kein Browser-Einstieg, `extensionKind: ui`, keine globalen Keybindings und damit kein F5-Override.

Zentrale Access-Policy verlangt exakt `local === true` und `trusted === true`. Manager, SSH-Probe, Host-Key-Befehl und Editor-Provider verwenden sie; vor dem Editor-Rename wird die Freigabe/Trust erneut geprüft. Manifest deaktiviert die Erweiterung für untrusted Workspaces. Der negative Policy-Test prüft fehlenden/false Trust und falschen Host vor einem Effekt; alle abgewiesenen Fälle erzeugen null Effekte.

`npm run quality`: Lint, Syntax, 20 Unit-Tests und Build bestanden. Echter VS-Code-1.140.0-Host-Smoke ohne Workspace bestand mit TreeView-/Settings-/Lazy-Activation-/F5-Manifestprüfungen sowie Webview-Start. Native TreeView-Registrierung schlägt bei ungültigen Beiträgen im Hosttest fehl.

Ein zusätzlicher Versuch mit isolierter installierter VSIX und Trust-eingeschalteten Einstellungen lieferte weiterhin `workspace.isTrusted = true`; dieser Fensterlauf ist **kein bestandenes Restricted-Mode-UI-Ergebnis**. Die Schutzentscheidung ist durch Manifest und negative gemeinsame Policy-Tests geprüft. Manuelles Umschalten/Bedienen des tatsächlichen Restricted Mode bleibt als native UI-Abnahme M6-01/M6-05 zu wiederholen. Die fehlgeschlagenen experimentellen Teststarter werden nicht als funktionierende npm-Befehle ausgeliefert. Temporäre Profile wurden entfernt; Benutzer-Trust blieb unverändert.

Grundlagen: [Tree View API](https://code.visualstudio.com/api/extension-guides/tree-view), [Workspace Trust](https://code.visualstudio.com/api/extension-guides/workspace-trust).
