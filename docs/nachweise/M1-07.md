# M1-07 – VSIX und CI

`npm run package` baut eine private VSIX unter `out/xscp-0.0.1.vsix`. Eine unabhängige Python-ZIP-Prüfung verifiziert Runtime-Bundles, Icon-Font und Lizenzhinweise sowie Ausschlüsse für Quellcode, Tests, Fixtures, tatsächliche Fixture-Geheimnisse, CI, Tools, Maps, native Addons und vorherige VSIX-Dateien. Keine Veröffentlichung und keine Änderung des normalen VS-Code-Profils.

`npm run test:installed` installiert die fertige VSIX in einem frischen temporären Benutzer-/Erweiterungsprofil. Die Harness enthält keinen xScp-Quellcode; der Test verlangt ausdrücklich den installierten Extension-Pfad. Desktop-Policy, Start ohne Projekt, Commands, lokaler Dateinachweis und der echte CSP-Webview-Handshake werden geprüft. Alles wird danach entfernt.

07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0, vsce 4.0.0: Quality (22 Unit-Tests, React-DOM-Test), Paketprüfung und installierter Extension-Host bestanden. VSIX ungefähr 525 KiB mit lokalen Codicons. Finale Paketgröße kann durch Dokumentation geringfügig variieren.

CI: Linux/macOS/Windows mit Node aus .nvmrc, npm ci, Quality und Packaging. Linux prüft zusätzlich die installierte VSIX unter Xvfb. Checkout/Setup Node stammen aus den offiziellen Repositories und sind auf SHA fixiert: [Checkout](https://github.com/actions/checkout/releases), [Setup Node](https://github.com/actions/setup-node/releases). Kein Remote-Repository vorhanden; gehosteter Lauf sowie tatsächliche Windows-/Linux-Desktop-Abnahme bleiben offen. Lokale Installation ist in README beschrieben.
