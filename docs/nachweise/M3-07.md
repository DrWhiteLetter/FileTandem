# M3-07 – Abbruch, Queue-Pause und Retry

Neue Starts lassen sich global pausieren; laufende Transfers behalten ihren Fortschritt. Abbruch beendet eigene SFTP-Ressourcen und gibt Zielpfadsperren frei, auch während einer Konfliktentscheidung. Gezielter Retry erzeugt neue Versuche ausschließlich für fehlgeschlagene, abgebrochene oder unterbrochene Aufträge; erfolgreiche Dateien werden nicht wiederholt. Elternabhängigkeiten bleiben erhalten. Unit-, Webview-, Build- und drei echte SFTP-Integrationstests bestanden.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
