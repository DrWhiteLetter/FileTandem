# M5-08 – Lokalisierung und Editor-Abnahme

Version 0.0.5 ergänzt Deutsch/Englisch für Manifest, Commander/Demo, Beschriftungen, Status, Menüs und native Dialoge. Sprachadapter übersetzt nur Anzeige-/Validierungstexte: Eingabewerte, Profilobjekte und kanonische Bestätigungsentscheidungen bleiben erhalten. `xscp.language` erlaubt auto/de/en; native Befehlstitel folgen VS Code. Reale UI- und Unit-Prüfungen sichern Sprachumschaltung, unveränderte Eingaben/Dateinamen, übersetzte Rückgabewerte und vollständige Manifest-Schlüssel ab.

SCP öffnet eine private lokale Kopie über den bestehenden echten SCP-Adapter und die gemeinsame Queue. Kein Watcher/Auto Save erzeugt einen Upload. Upload verlangt ausdrückliche Entscheidung und prüft den ursprünglich heruntergeladenen SHA-256 vor/nach Transfer; auch eine fremde Änderung gleicher Länge wird blockiert. Unhochgeladene Kopien überleben Neustart, Aufträge starten dabei nicht automatisch. Cache-Metadaten sind streng begrenzt/validiert; eigene Kopien können bewusst bereinigt werden. F4 bietet die native SFTP-Freigabe an; F3 bleibt lesend.

Abschlussreview: Lesezugriffe anderer Erweiterungen dürfen die Basis eines angezeigten, noch alten Dokuments nicht verändern. Baseline folgt nur der tatsächlich geladenen Fassung oder ausdrücklichem Review, nicht jedem `workspace.fs.readFile`. Eigenständiger nativer Regressionstest verhindert hierbei stille externe Überschreibung. Pro URI begrenzter Inhalt, höchstens 32 gehaltene Dateien; Schließen einer Ressource beendet keine anderen Dateien desselben Authorities/SSH-Transports.

Nachweis: 07.10.2026, macOS arm64/VS Code 1.140.0 (UI Node 24.21.0), Node 22.13.1, OpenSSH/Debian-Fixtures, Remote-SSH 0.128.0. 47 Unit-/drei gerenderte React-Tests, Lint/Check/Build und 31 reale Protokolltests bestanden. Installierte VSIX in englischem lokalem Fenster und echtem Remote-SSH-Fenster: Produktions-SFTP-Provider, URI/Rechte/Verzeichnislesen, manuelles/automatisches Speichern, Dirty-Erhalt, Konflikte/Review/Diff, unabhängige Tabs und SCP-Kopie bestehen. Eine echte Workspace-Erweiterung auf dem anderen Host liest den Desktop-Provider; lokaler Marker ist dort nachweislich nicht vorhanden. Native Kontrast-/Zoom-Prüfung mit 10.000 realen Dateien sowie normale installierte Starts/Neustart ergänzen die Abnahme. ZIP-Prüfung bestätigt beide NLS-Dateien, lokale Assets/Notices und Ausschluss von Fixture-Geheimnissen/Native-Addons.

Reproduzieren: `npm run quality`, `XSCP_DOCKER_CONTEXT=colima-xscp npm run test:protocols`, `npm run package`; anschließend `node scripts/test-editor.mjs --installed --english`, `node scripts/test-editor.mjs --installed --remote --english`, `node scripts/test-editor.mjs --accessibility` und `npm run test:browser:installed` mit `VSCODE_TEST_EXECUTABLE` auf die lokale VS-Code-Programmdatei.
