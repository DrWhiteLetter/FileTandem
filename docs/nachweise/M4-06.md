# M4-06 – Journal-Wiederherstellung vervollständigen

Die Queue bietet bewusst gestartete SFTP-Fortsetzung, vollständigen Neustart und eine native Bestätigung zur Bereinigung genau einer zugeordneten eigenen Teil-Datei. Geänderte/fehlende Profile, unpassende Pfade/Typen und laufende Zielpfadsperren verhindern unsichere Bereinigung. Gemeinsame Teil-Datei-Zuordnungen werden anschließend invalidiert; das veröffentlichte Ziel bleibt erhalten. Das atomische Journal ist mit HMAC geschützt; der Integritätsschlüssel liegt ausschließlich in VS-Code-SecretStorage. Manipulation wird quarantänisiert, sichere alte M3-Metadaten bleiben lesbar. Quality, echte Resume-/Cleanup-Tests und zwei reguläre isolierte Starts der installierten VSIX bestehen. Keine automatischen Verbindungen, Schreibvorgänge oder Löschungen beim Laden.
