# M3-06 – Transferbefehle und Queue

Upload/Download für Commander-Einzel-/Mehrfachauswahl, native Dateien-/Ordnerauswahl, Download-nach-Dialog und lokaler Explorer-Befehl. Explorer-URIs werden auch zur Laufzeit auf lokale file-URIs geprüft. Session-Queue im verbundenen Commander, globale Queue über Transfers-anzeigen; Bytes, Rate, Status und öffentliche Fehlertexte, maximal 200 sichtbare Zeilen. Fortschrittsnachrichten auf zehn pro Sekunde begrenzt; Zustandswechsel sofort. Browser-Refresh nach Abschluss, nicht pro Datenchunk. Dateiinhalte bleiben im Backend. Quality inklusive React-Tests bestanden; echte Transfer-/Baumtests prüfen denselben Engine-Einstieg. Native installierte Komplettabnahme folgt M3-09.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
