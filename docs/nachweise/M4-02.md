# M4-02 – SCP-Sender und Empfänger integrieren

Die gemeinsame sichere Transferpipeline kann nun einen SCP-Streamer verwenden. SCP sendet und empfängt über eigene Exec-Kanäle ohne PTY oder SFTP-Fallback, begrenzt Inhalt auf 64-KiB-Abrufe und verlangt vollständige Bytes, ACKs, EOF und Exitstatus 0. Produktions-Abbruch schließt nur den eigenen Kanal; der verifizierte Transport bleibt nutzbar. Lokale Quellen werden ohne Symlink-Folgen geöffnet. Quality und vier echte SCP-Tests bestanden: 16 MiB in beide Richtungen, Leerdateien, Quotes/Sonderzeichen, unabhängiger OpenSSH-Hashvergleich, negative Serverfälle sowie Abbruch mit anschließend nutzbarem Transport.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
