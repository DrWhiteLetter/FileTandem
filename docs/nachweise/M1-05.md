# M1-05 – Theme und Grundnavigation

VS-Code-Farbvariablen, unverändert lokal gebündelte Codicons, sichtbarer Tastaturfokus und zusätzliche High-Contrast-Rahmen. Auswahl hat außerdem ein Häkchen und hängt nicht allein von Farbe ab. Beide Listen haben je einen Tab-Einstieg; Pfeile, Home/End wechseln Auswahl/Fokus, Enter öffnet Demo-Ordner, Leertaste wählt aus, Backspace geht zum Elternordner. Schmale Ansichten stapeln die Bereiche, statt Schrift zu verkleinern. F5 bleibt unverändert.

07.10.2026: `npm run quality` bestanden, einschließlich gerendertem React-Test für Tastaturfokus/Zeilenwechsel und Auswahl. Lokale Font-Datei ist im Build; CSP erlaubt Fonts nur aus lokalen Webview-Assets. Codicons-Version 0.0.46-24, Upstream-Lizenz und Attribution sind im Paket enthalten.
