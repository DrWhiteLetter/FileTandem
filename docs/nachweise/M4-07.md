# M4-07 – Agent und interaktive Anmeldung

Gespeicherte Profile können ausdrücklich einen Unix-SSH-Agent oder interaktive Anmeldung mit mehreren Serverabfragen wählen. Native Eingaben beachten echo und Abbruch; Antworten werden weder automatisch aus Passwörtern übernommen noch gespeichert/protokolliert. Agent Forwarding bleibt aus. Expliziter Retry/Fortsetzung kann nach Prüfung des Auftrags erneut verbinden und authentifizieren; Journal-Laden startet keine Verbindung. Profil-/Benutzer-/Protokolländerungen invalidieren alte Aufträge bzw. Sitzungen. Quality und fünf echte Auth-Tests bestehen: Passwort, Ed25519/RSA, verschlüsselte Keys, isolierter Unix-Agent, PAM-Keyboard-Interactive einschließlich Abbruch, falscher Antworten und Host-Key-Ablehnung vor Prompts; neue Anwendungstests übertragen Bytes und verbinden erneut. macOS/Unix-Agent ist abgenommen; Windows OpenSSH Named Pipe bleibt für die Plattformmatrix M6 offen, Pageant/Cygwin werden klar abgewiesen.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
