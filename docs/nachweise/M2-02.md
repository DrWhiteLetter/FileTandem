# M2-02 – SecretStorage und Anmeldung

Native maskierte Passwort-/Passphrasendialoge, lokale begrenzte Schlüsseldateien und expliziter Agent-Pfad. Geheimnisse werden über deterministische Referenzen in context.secrets verwaltet, nicht im Profil oder Export. Speichern erfolgt erst nach erfolgreichem Verbindungsaufbau; Abbruch schreibt nichts. Profil-Löschen und der Vergessen-Befehl entfernen gespeicherte Anmeldung. Unit-Tests prüfen Abbruch, verzögertes Speichern und Bereinigung des Schlüsselbuffers; npm run quality bestanden. Die realen Passwort-/Key-Verbindungsabläufe werden zusätzlich in den gemeinsamen M2-Integrationstests geprüft.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
