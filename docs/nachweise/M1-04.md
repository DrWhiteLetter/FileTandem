# M1-04 – Commander mit Mock-Daten

Zwei unabhängige Dateibereiche mit Ordnernavigation, Auswahl, Sortierung, Filter, Pfadleisten und veränderbarer Breite. Toolbar, Status und einklappbare Demo-Queue sind umgesetzt. Die fünf Zustände bereit, ladend, leer, Fehler und getrennt lassen sich umschalten. Transfers sind ausdrücklich noch deaktiviert; es werden keine Dateien oder Server verändert.

Nachweis am 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0: `npm run quality` bestanden (21 Unit-Tests und gerenderter React-DOM-Test). Der DOM-Test prüft Auswahl, Ordnerwechsel, Queue, Zustände und die Textdarstellung eines HTML-artigen Dateinamens. Der echte Extension-Host-Test bestätigt den Webview-Handshake mit lokalen CSP-Assets. Native visuelle Theme-Abnahme folgt separat.
