# M1-01 – Module und Qualitätsbefehle

7. Oktober 2026. Commit: `refactor(M1-01): separate application and domain and add quality checks`.

Domain enthält reine Dateilistensortierung (Ordner zuerst, numerische Metadaten, unveränderte Quelle). Application orchestriert die vorhandene SSH-Authentifizierungsprobe über einen injizierten Connector; Adapter und VS-Code-Integration bleiben getrennt. M0-Code wird übernommen, keine neue SSH-Implementierung.

ESLint 10.12.0 und globals 17.13.0 exakt im Lockfile; die unterstützte Node-Engine umfasst Entwicklungs-Node 22.13.1. Flat Config prüft JS/JSX/CJS und verbietet Domainimporte aus VS Code, React, SSH, Node und höheren Schichten. JSX wird geparst; unbenutzte JSX-Bezeichner werden ohne zusätzlichen React-Lintplugin nicht geprüft. Syntaxprüfung entdeckt neue Module automatisch. Quellcode bleibt JavaScript.

`npm run quality` (Lint, Syntax, 19 Unit-Tests, zwei Bundles) bestanden. Domain-Sortierung hat einen semantischen Test für Ordnerpriorität, numerische Sortierung und Nichtmutation. M0-Transport-/Editorproben bleiben vorhanden.

Befehle: `npm ci`, `npm run lint`, `npm run check`, `npm run test:unit`, `npm run build` oder kombiniert `npm run quality`. Host-Smoke weiterhin `npm test`. Grundlage: [ESLint Flat Config](https://eslint.org/docs/latest/use/configure/configuration-files), [Importgrenzen](https://eslint.org/docs/latest/rules/no-restricted-imports).
