# M5-01 – Sitzungsgebundener lesender Editor

Opaque UUID-Authorities unter `xscp:` enthalten weder Host noch Benutzer oder Geheimnisse. Interne Zuordnung bindet Profil und konkreten Transport; Wiederverbinden erzeugt neue Ressourcen. `stat`, `readDirectory` und begrenztes `readFile` laufen auf dem Desktop. Dateiöffnung per Doppelklick/Enter im Commander, standardmäßig schreibgeschützt. Über 10 MiB wird Streaming-Download angeboten; Symlinks sind keine editierbaren Dateien. Eigener Metadaten-/Dateikanal, Schließen beendet nicht den gemeinsamen SSH-Transport. Fehler für fehlende Dateien/Rechte werden als FileSystemError umgesetzt. Profil-Speicher-API gibt nun das gespeicherte Profil zurück und prüft dessen Identität beim Trennen.
