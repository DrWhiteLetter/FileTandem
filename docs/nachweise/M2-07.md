# M2-07 – Ordner und Umbenennen

Native Namensdialoge für lokales/entferntes mkdir und rename. Dateiaktionen akzeptieren ausschließlich IDs der aktuell angezeigten Liste, prüfen Namen und verweigern veraltete Auswahl bzw. Ordnerwechsel während des Dialogs. Vorab-Konfliktprüfung; lokales VS-Code-rename mit overwrite:false und standardmäßiges SFTP-rename ohne überschreibende OpenSSH-Erweiterung. Erfolg aktualisiert den Bereich. Quality, Namens-/Konflikt-Unit-Test und echter SFTP-only-Test mit Unicode, Leerzeichen, Apostroph/Ampersand sowie vorhandenen Zielen bestanden. Fremde Server müssen den SFTP-Vertrag einhalten; konkurrierende externe Änderungen sind keine transaktionale Dateiverwaltung.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
