# M5-04 – Diff, Ereignisse und begrenztes Polling

Nativer Diff zeigt unveränderliche Fassungen „Server ↔ Editor“, einschließlich ungespeichertem Editorinhalt. Eine zusätzliche Referenz-URI hält die ursprüngliche Speicherbasis. Übernahme betrifft nur den zuletzt verglichenen Serverstand. Keine temporären Inhaltsdateien auf Platte: Snapshots liegen begrenzt im Speicher (24 Fassungen/64 MiB), verschwinden bei Dokument-/Sitzungsende und werden bei weiteren Vergleichen verdrängt. Eigene Saves melden Changed; nur die aktive SFTP-Datei wird seriell mit SHA-256 geprüft (2–60 Sekunden, Standard 5). Bei inaktivem/geschlossenem Dokument, Disconnect oder Dispose kein fortlaufender Timer. Ein sauber neu eingelesenes Dokument erhält eine inhaltlich geprüfte neue Referenz; Dirty-Dokumente behalten ihre Basis.

Nachweis: 07.10.2026 macOS arm64/VS Code 1.140.0/Node 22.13.1. Quality und reales Editor-Fenster bestehen. Diff-Fassungen separat über VS-Code-Contentprovider geprüft (Editorentwurf, externer Serverstand, Baseline); aktive Prüfung liefert Ereignisse, bewahrt Dirty-Text; nach Schließen keine Session, kein Snapshot/Timer. SFTP-only und bisherige Auto-Save-Regression grün. Commit: Item-Commit mit dieser Datei.
