# M2-04 – Lokaler Browser

Echter Desktop-Dateibrowser startet ohne Workspace im Home-Verzeichnis bzw. Profil-Startordner. readdir/lstat/stat, Pfadeingabe, Elternordner, Vor/Zurück und Refresh sind angebunden. Nur lokale file-URIs ohne Authority werden angenommen; Remote-URIs werden vor Dateizugriff abgewiesen. Symlinks werden als Links dargestellt. Fehlende Pfade/Berechtigungen erscheinen im Bereich. Tests mit temporären lokalen Ordnern prüfen Navigation, Verlauf, stat, Links und Fehler; Quality und echter Extension-Host-/Browser-Handshake bestanden. Mock-Demo bleibt als separater Befehl verfügbar.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
