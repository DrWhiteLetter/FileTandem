# M3-09 – SFTP-Alpha abnehmen und paketieren

Private VSIX 0.0.3 erstellt und unabhängig auf Paketinhalt, lokale Assets sowie fehlende Fixture-Geheimnisse/Native-Addons geprüft. Fünf echte Integrationstests bestehen: binärer bidirektionaler Hash-Rundlauf, Backpressure/Abbruch, sichere Veröffentlichung, alle Konfliktentscheidungen inklusive Namenskollision, rekursive und leere Ordner, SFTP-only ohne Shell sowie Passwort und verschlüsselter Key. Frisch installierte VSIX besteht zwei reguläre isolierte VS-Code-Starts: echter Webview, Transfers nach Tab-Schließen, Journal-Unterbrechung ohne automatischen Schreibvorgang und einzelner expliziter Retry. 38 Unit-Tests, zwei gerenderte React-Tests, Lint/Syntax/Build bestehen. Alpha-Anleitung und Grenzen: [M3-Alpha](M3-Alpha.md).

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
