# M2-08 – Löschen und Eigenschaften

Lokales Löschen verwendet ausschließlich den VS-Code-Papierkorb; ein Fehler wird weitergegeben, ohne endgültigen Fallback. Native Bestätigung nennt Auswahl, Ordner und Umfang. Remote-Löschen ist ausdrücklich endgültig und bestätigt einen vorab begrenzten Postorder-Plan; lstat und No-Follow-Auflistung traversieren keine Symlink-Ziele. Typänderungen/ersetzte Eltern werden vor einzelnen Löschschritten abgewiesen. Eigenschaften und chmod sind angebunden; lokale chmod hält einen mit O_NOFOLLOW geöffneten Deskriptor, Remote-Symlinks werden verweigert. Quality sowie echte SFTP-only-Tests für chmod, rekursive Löschung und einen Link auf /data bestanden; der außerhalb liegende Marker bleibt bytegleich. Unit-Test bestätigt keinen endgültigen Fallback bei Papierkorbfehler. SFTP v3 bietet keine transaktionale No-Follow-Pfadoperation: gleichzeitige externe Pfadänderungen bleiben eine dokumentierte Protokollgrenze. Windows-POSIX-chmod wird mit verständlicher Meldung verweigert.

Umgebung: 07.10.2026, macOS arm64, Node 22.13.1, VS Code 1.140.0. Commit: Item-Commit mit dieser Datei.
